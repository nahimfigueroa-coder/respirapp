RESPIRAPP — PWA

Contenido:
- index.html: aplicación
- manifest.webmanifest: configuración instalable
- sw.js: funcionamiento offline/cache
- icons/: iconos para iPhone y navegadores

INSTALACIÓN EN IPHONE
1. Publica esta carpeta en un sitio HTTPS (por ejemplo, un hosting estático).
2. Abre la URL publicada en Safari.
3. Pulsa Compartir.
4. Selecciona “Añadir a pantalla de inicio”.
5. Abre RespirApp desde el nuevo icono.

Nota: una URL file:// no permite instalar una PWA de forma completa. El servicio debe usar HTTPS.
